# Dataset report

Generated by `python -m experiments.inspect_dataset`. Format: Terraform (`*.tf`) + `labels.json` (ground truth `has_pe`, `min_len`, witness; injected planted paths, dead ends, decoys; `dfs.paths` for the small configs) + the generator's `config.json` (not used as ground truth, see docs/HANDOFF.md). Converted by `iampe/parser/to_tac.py`. Sizes below are entity counts from `config.json`.

## Splits

All 72 configs come from one generator (`iamgen`; 18 in `esc.zip` + `no_esc.zip`, 54 in `more.zip`). Its seed puts each config in a size tier: 6e7 (~50 graph nodes), 7e7 (100-350), 8e7 (500-2,300), 1e8 (5k-30k+).

- **train / val / test** (tiers 6e7-8e7): the 8 configs of the first release keep their old split; the rest are spread about 60/20/20 within each (tier, has_pe) group, in seed order. So every split has every size and both labels. `val` is for model selection, `test` only for the final tables.
- **bench**: the four IAM Vulnerable scenarios (tiny, hand-made).
- **large** (tier 1e8): evaluation only. The three over 15 MB of Terraform are built on the GPU machine (`build_graphs --large --allow-large --missing`).
